# pokeldn 日本語パック

画面の英語を日本語に切り替える追加パックです。本体の再ビルドは不要です。

[日本語パックをダウンロード](https://github.com/nantekool/pokeldn-ja/raw/refs/heads/main/pokeldn-ja-1.2.0.pokeplugin)

## v1.2.0 の更新内容

pokeldn **v0.45.0** に対応。バンクの図鑑・能力値表示、接続方法とゲーム機側の役割の選択、LAN経由の交換・レイドの案内など59項目を追加し、削除された5項目を整理しました。

既存パックの利用者は「プラグイン」から新しい `.pokeplugin` ファイルを選んで更新し、アプリを再起動してください。

## 導入

1. pokeldnを起動し、サイドメニューの **Plugins** を開きます。
2. **Add a plugin** または **Add a .pokeplugin file** から `pokeldn-ja-1.2.0.pokeplugin` を選びます。画面にファイルをドロップしても追加できます。
3. 内容を確認して **Install** を押します。
4. **Settings → App language** で **日本語** を選びます。
5. pokeldnを終了し、もう一度起動します。

元に戻す場合は「設定 → アプリの言語」でEnglishを選び、再起動してください。
一覧に「日本語」が出ない場合は、プラグインのインストール結果を確認してください。古いアプリで非対応と表示された場合は、本体の更新が必要です。

## 対応範囲

- 上流の英語UI辞書にある **1,791項目すべて**を収録。
- ボード、バンク、交換、レイド、ユニオンサークル、マクロ、おくりもの、GTS、設定、プラグイン管理などを翻訳。
- 共通するメッセージ1,266項目と、ゲーム名などの用語31項目も収録。
- 言語コードは `ja`。ポケモン名・技・特性などは、本体のPKHeX連携が提供する日本語表示を使用します。日本語データそのものはこのパックには含みません。
- アプリの言語と、作成するポケモンのトレーナー言語は別設定です。必要なら「自分のトレーナー」の言語も確認してください。

詳細タブのツール固有ヘルプ、内蔵ドキュメント、一致しない追加モジュールのメッセージ、実行ログには英語が残ります。ファイル名、通信データ、ユーザーが入力した名前は翻訳しません。Showdown入力例や検索例も、入力として使える英語を維持しています。

この版はパソコン向けの表現を基本としています。スマートフォンで表示される一部の案内にも「パソコン」と表示される場合があります。

## 検証と対象版

- 元リポジトリ: https://github.com/Decryptu/pokeldn
- 参照コミット: `bd876979a75a676943b87fe05e7a1ac268dabf30`
- 言語パックAPI: `1.9`、パック版: `1.2.0`
- 原文とのキー照合: 欠落0、余分0。
- 差し込み変数・書式指定の照合: 不一致0。
- アプリの言語ローダーで全1,791項目の読み込み・書式適用を検証。
- アプリ標準のパッケージ作成・読み取り検証を通過。
- 日本語の選択、未翻訳文の英語フォールバック、英語への復帰を確認。

GUIでの表示崩れ、ESP32・Switch実機での操作、PKHeXサービスからの日本語名取得は未検証です。標準の `check_language_pack.py` 全体は、この環境に `Crypto` がないため実行完了していません。代わりに上記の辞書・書式・ローダー検証を実施しています。

上流で文言が追加された場合、未収録の項目は英語表示になります。ゲーム画面の選択肢はソフトの言語・バージョンによって表記が異なる場合があります。

## 翻訳の編集

このリポジトリの各TOMLファイルが編集用ソースです。`strings.toml` の左側のキーは変更せず、右側の訳文を編集します。`{value0}`、`{name}`、`{value0:.0%}` などの差し込み指定は維持してください。

上流リポジトリと実行環境がある場合は、次のコマンドで再梱包できます。

```text
python scripts/pack_plugin.py PATH_TO/pokeldn-ja -o pokeldn-ja-1.2.0.pokeplugin
```

配布パックは翻訳データのみで、実行コードは含みません。署名は付けていません。上流の英語文言を基にした翻訳として、同梱のAGPLv3ライセンスを適用します。上流の公式配布物ではありません。
